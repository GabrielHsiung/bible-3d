# 會幕 3D：美術與體驗聖經（Art Bible）

目標：一個**寫實、沉浸式**的網頁體驗遊戲。玩家以第三人稱走進西奈曠野中的會幕，像《刺客教條》的「探索之旅」模式：
安靜、莊嚴、有聲音、有生活感；同時每件器具都能對照經文和肘數。標竿是 Athenaion（`/home/claude/ref/athenaion`，
three.js 程序生成的寫實希臘世界），但我們必須**即時可玩**，手機也要跑得動。

## 畫面
- 時間：清晨到上午，陽光從東南方低角度斜照（約 25–30°），暖色；陰影偏冷藍、不死黑。
- 地景：淺褐色沙地＋碎石，遠方是紅褐色花崗岩山（西乃），空氣透視讓遠山偏淡偏藍。
- 營地：黑山羊毛帳棚圍繞會幕，有炊煙、人走動、羊群。
- 會幕外罩是深色皮革／山羊毛，院子帷子是白色細麻、會垂墜有皺褶，門簾是藍紫朱紅繡花。
- 金器（燈臺、桌子、香壇、法櫃、帳幕豎板）要像真的金子：錘打痕跡、反射燈火；銅器（祭壇、洗濯盆、卯座）是暖銅色，有使用痕跡和煙燻。
- 火焰要像真的火：用 shader（噪聲＋漸層＋閃爍、加法混合），**不要用圓錐體**。燈臺頂端是七盞小油燈（陶或金燈盞＋燈芯＋小火苗）。
- 曝光參考：中間調不要灰、不要糊；高光不要死白。後製已有 AgX、N8AO、Bloom。

## 可信度
每件東西分三級：經文明載（text）／考古文獻（arch）／學者推測（infer）。經文沒寫的細節可以做，但說明文字要標為推測。

## 效能預算（手機也要能跑）
- 目標：中階手機 30fps、電腦 60fps。總三角形數 < 1.5M；draw call < 600（重複物件用 InstancedMesh 或合併幾何）。
- 不載入外部檔案（網址會被擋）；所有幾何、貼圖、聲音都在程式碼中產生。
- 單檔輸出（`SINGLE=1 npx vite build --outDir dist-single`）必須能跑。
