## 總覽

《聖經 3D 世界》是網頁上的沉浸式探索遊戲：玩家親身走進會幕、所羅門聖殿、希律聖殿與耶穌時代的耶路撒冷，每件建築和器具都能對照經文、肘數與可信度。

- 體驗定位：像《刺客教條》探索之旅模式加上《Journey》的安靜莊嚴；有故事章節、自由探索、時間軸綜觀三種主要玩法。
- 平台：瀏覽器即開即玩，電腦與手機都支援；以 claude.ai 網頁發布，原始碼在 GitHub `GabrielHsiung/bible-3d`。
- 畫質標竿：Athenaion（three.js 程序生成的寫實希臘世界）；我們必須即時可玩，所以加上「拍照」路徑追蹤模式補足離線畫質。
- 資料原則：每件東西分三級可信度：經文明載／傳統文獻／重建推測。經文用和合本；參考圖集《3D聖經世界》只參考造型，不複製圖片。
- 編號規則：樂高式編號，字母是區塊、數字是零件（A-1、A-2…）。

## 遊戲模式

| 模式 | 玩家做什麼 | 參考作品 | 關鍵技術 |
|---|---|---|---|
| 故事章節 | 依章節扮演祭司、朝聖者、門徒，完成任務、觀看經文事件過場 | 《刺客教條》主線、《The Last of Us》章節選單 | 任務系統、過場運鏡、字幕與配樂 |
| 自由探索 | 在任一場景自由走動，靠近器具就看經文與尺寸 | 《刺客教條》探索之旅 | 第三人稱控制、觸發區、經文卡 |
| 時空綜觀 | 從橄欖山俯瞰耶路撒冷，拖動時間軸看城市從主前 1000 年到今日的變化 | 《文明帝國》、Google 地球時光延時 | 真實地形、分期建築切換、時間軸 UI |
| 導覽 | 自動沿路線慢走，字幕逐段講解 | 博物館語音導覽 | 路徑導航、字幕、景深 |
| 攝影模式 | 凍結畫面、調角度，用路徑追蹤算出寫實照片 | 大作的拍照模式 | GPU 路徑追蹤、累積取樣 |
| 圖鑑與測驗 | 收集看過的器具、地點、人物，答題複習 | 《老頭環》物品說明、博物館圖鑑 | 存檔、收集系統、題庫 |

## 技術架構

| 層 | 技術 | 說明 |
|---|---|---|
| 前端框架 | Vite＋React＋TypeScript | 單頁應用，單檔輸出供 claude.ai 發布 |
| 3D 引擎 | three.js＋React Three Fiber＋drei | 場景圖、材質、相機 |
| 物理 | Rapier（WebAssembly） | 角色碰撞、相機射線 |
| 即時渲染 | PBR 程序材質、環境反射探針、陰影、postprocessing（N8AO、Bloom、AgX、景深） | 畫質依裝置自動分級 |
| 離線級畫質 | three-gpu-pathtracer | 攝影模式累積取樣 |
| 音訊 | Web Audio 程序合成 | 配樂、環境音、3D 定位音源；不載入音檔 |
| 狀態 | zustand | 遊戲階段、選單、設定 |
| 資料 | JSON：經文（和合本）、器具、章節、時間軸事件 | 可信度三級 |
| 場景管理 | 每個場景一個模組，依需要分段載入 | A-6 |
| 存檔 | localStorage（可能被瀏覽器清除，需容錯） | A-7 |
| 版本控管 | GitHub，agent 各自分支開發，主控合併 | docs/CONTRACT.md |

效能預算：中階手機 30fps、電腦 60fps；三角形 < 1.5M、draw call < 600；所有幾何、貼圖、聲音皆程序生成。
